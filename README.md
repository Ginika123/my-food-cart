my food cart

my food cart is a mini shopping cart web project where users can browse food items and add them to a cart.

 Features
- Display food items in a 3-column grid layout
- Show each item with image, name, price, and “Add to Cart” button
- Dynamically update the number of items in the cart
- Clear the cart for a fresh start

 Technologies Used
- HTML
- CSS
- JavaScript

 How to Use
1. Open `index.html` in a web browser
2. Click **Add to Cart** to add any food item
3. View items in the cart on the right
4. Click **Clear Cart** to reset the cart
